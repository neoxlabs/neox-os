### 1.1 agent 侧的工具

**一直都在的 10 个**：`list_dir` `read_file` `write_file` `edit_file`(内容寻址)
`search` `find_files` `run`(sh -c，退出码 + 头尾保留)
`request_access`(申请能力，等人时不设时限) `fetch`(取网页，HTML 抽正文再分片)
`recall`(查以前的对话；当前这段排除，结果走工具不进提示词)

**这台机器配了才挂的**：`web_search`(配了 `NEOX_SEARCH_KEY`)、
`view_image`(主模型认图或另配了视觉模型)。**没配就不出现在工具表里** ——
摆一个配不出结果的工具，模型会先对用户许诺再拿到一句"这台机器没有"，
用户看到的是一次失约。

**纠正（不是工具）**：用户明确改方向时（"不是这样"、"用分不要用元"、"算了还是"、点了拒绝）OS 自动落账。下一进程启动时以冻结摘要进提示词，空就不加。问句不认。真机没跑过。

**边界在内核不在工具表**，所以 `run` 敢给到底：子进程继承同一套 landlock /
netns / cgroup，这是内核语义不是我们的约定。

### 1.2 提示词（2026-08-15 重写）

系统段 13531 字节 / 12 层，加工具声明 5914 = **前缀 19445 字节**，
`TestPromptPrefixStaysLean` 钉着 20000。

这一版删掉的是十二条"某工具报某错怎么办"的清单——**那些话工具自己在出错
那一刻就会说**（`tools.go` 的 `actionable`），命中率比提示词高得多，
写在前缀里只在稀释注意力。原则改成：**场景细节留给工具的错误文本，
提示词里只留跨场景成立的判断方式。**

补上的两条通用性：**跟随用户的语言**（整份提示词是中文，不说清它就中文答
英文问题），**完成条件不再只是代码形状**（骨架改成"要有一个独立于你判断的
证据"，跑测试只是其中最强的一种）。

## 2. 明确还差的（不许当成做完了）

| 差什么 | 实情 |
|---|---|
| **强制只在 Linux 成立** | macOS 上探测直接报"强制约束只在 Linux 上可用"，等于没有笼子。开发在 Mac、验收必须在 VM |
| **landlock ABI 偏老** | 自检自己就报"只能部分强制（缺少较新的访问位）"。拦得住写，但不是完整的那套 |
| **PDF** | `isBinary` 直接拒，读不了。图片已经能看了（`view_image`），PDF 还不行 |
| **长任务的待办面** | 没有。步数无限 + 停滞检测兜底，但用户看不见"它打算分几步" |
| **两份实现并存** | `packages/` 那 4020 行 TypeScript 仍挂在 `npm run check` 上。**这是本仓库现在最大的双真相源**——按第 3 节的判据，它排在所有新功能前面 |
| **部署的二进制会漂** | `/usr/local/bin/neox-chat` 落后于 `~/nx/neox-chat`。同一台机器两个路径，早晚拿错一个 |

## 4. 判据

1. **有没有第二个地方在回答同一个问题？** 有 → 先合并再说
2. **它买到的好处能不能量？** 不能量的先别做
